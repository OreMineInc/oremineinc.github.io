# {% include astral-icon.html model="spinel" class="page-title-icon" %} Голосовой чат

Работа голосового чата на сервере обеспечивается модификацией **Simple Voice Chat**.

- **Установка:** воспользуйтесь [пошаговым гайдом по установке VoiceChat для OreMine](https://telegra.ph/Ustanovka-VojsCHata-dlya-OreMine-11-12). Инструкцию также можно открыть в игре командой `/voice`.

- **Применение:** используйте чат для общения и координации во время совместной игры, добычи ресурсов, PvP-сражений и серверных событий.

- **Правила:** запрещено использовать голосовой чат для оскорблений, угроз, рекламы и распространения запрещённого контента.
