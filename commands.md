# ⌨️ Команды сервера

## Структура меню /info

Кнопки главного меню: Начало, Правила, Выживание, Приваты, PvP и рейды, Экономика, Кланы, События, Донат, Команды, Безопасность, FAQ/Поддержка.

## Полезные команды

| Команда | Назначение |
| --- | --- |
| `/info` | Открыть меню гайдов |
| `/spawn` | Телепортироваться на спавн |
| `/rtp` | Случайная телепортация |
| `/home`, `/sethome` | Вернуться домой или установить точку дома |
| `/tpa <ник>`, `/tpaccept`, `/tpacancel` | Отправить, принять или отменить запрос телепортации |
| `/msg <ник> <текст>`, `/r <текст>` | Личное сообщение и быстрый ответ |
| `/balance` | Проверить баланс монет |
| `/pay <ник> <сумма>` | Передать игровую валюту |
| `/shop`, `/seller`, `/ah` | Магазин, скупщик и аукцион |
| `/report <ник> <причина>` | Подать жалобу на игрока |

> ℹ️ Неизвестная команда? Используйте `/help`, проверьте `/info` или обратитесь к администрации.
